# Nova Calculator — CodeAlpha Task 2

A responsive dark-theme calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, division, percentage, decimals, sign toggle
- Clear and delete controls
- Keyboard support: numbers/operators, Enter or `=`, Backspace, Escape
- Responsive layout, accessible labels, error messages, subtle hover animations
- Accent theme toggle

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No build tools or dependencies are required.

## Keyboard
- `0–9`, `+`, `-`, `*`, `/`, `%`, `.`: enter values
- `Enter` or `=`: calculate
- `Backspace`: delete last character
- `Escape`: clear

Create a public repository named `CodeAlpha_Calculator`, then upload the files in this folder. Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root** if you want a hosted demo.
